ProsperoLight streaming tiles, a PS5X360 game list, settings that stick, and hold Circle to close the app.

### Added
- **ProsperoLight as a target app.** Make a home-screen tile that starts a PC game stream: pick one of ProsperoLight's paired PCs and one of that PC's apps from a list with box art, which also becomes the tile icon. Needs ProsperoLight 01.000.100 or later. (#8, by @blackbearreloaded)
- **PS5X360 game list.** For PS5X360 the first row is now "Game", which lists the games PS5X360 finds in its game folders, with their covers. The tile gives PS5X360 the game's full path, which is how it starts a game, so a PS5X360 tile now opens straight into its game. "Choose a file or folder" covers games in folders added in PS5X360's own settings. (#13, by @heydemoura)
- **Hold Circle for 3 seconds on the home screen to close the app.** A bar fills while Circle is held. (#15, by @heydemoura)

### Changed
- **ROM file first.** The ROM file is now the first row when making or editing a forwarder, and picking one fills an empty display name with the file name. (#11, by @heydemoura)
- **Keyboard.** The on-screen keyboard is opaque, and R2 confirms. R1 switches to symbols. (#10, by @heydemoura)
- **Payload target hidden.** The "Payload" target app is hidden behind a feature flag that is off by default. (#12, by @heydemoura)

### Fixed
- **Forwarders folder kept.** A custom forwarders folder is no longer reset to /data/homebrew when the app restarts. Settings are now kept in /data/forwarder-manager. (#14, by @heydemoura)

### Requirements
- A jailbroken PS5 with elfldr on port 9021.
- ShadowMountPlus, to register the app and the forwarders it creates.

### Install
Unzip `PPSA99930.zip` and copy the `PPSA99930` folder to `/data/homebrew/`, replacing the old one. Your forwarders are kept.
